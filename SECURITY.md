# Security Policy

This repository should not contain user data, app telemetry, account data, API keys, or paid-provider credentials.

## Supported Version

Only the default branch is maintained.

## Reporting

For non-sensitive bugs, open a GitHub issue.

For sensitive security issues, avoid posting credentials or exploit details publicly. Use GitHub's private vulnerability reporting feature if it is available for this repository, or contact the maintainer through GitHub with a minimal non-sensitive description first.

## Data Safety

Please do not include:

- API keys
- paid market data
- private provider responses
- user portfolios or watchlists
- copyrighted news article bodies
